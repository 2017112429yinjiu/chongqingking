# R19 场景自审 · 2026-11-20 · 内部迭代

用户指出上一轮只改人物/骑行、没有继续推进场景。这一轮实际转向面馆—中央梯坎的场景美术。当前仍明显低于电影级和实景照片要求，不封包，不把测试通过称作美术验收。

## 当前组成

- R17 基础城市 GLB 保持原样；R19 第05次细节层为52个对象，包括7个简化物理代理，19级原有踏步的分块表面、挡边、生活物件与远景地形。不是重新建成52栋建筑。
- 面馆店招改比例、包边、螺钉及局部掉漆；重做有悬垂和褪色变化的薄布雨棚，补独立支撑的灯具、排烟管和墙上线路卡扣。
- 两把旧塑料椅、一张旧木桌、碗筷与调料罐组成用餐位置；盆栽放在住户与梯坎边缘。原垃圾组移入侧面服务间隙，保留所有原物件。店主取餐区域保持开放。
- 材质保留原始 PBR 与米制 UV，增加有限的矿物色差、面馆墙脚/排水处返潮；不把整个世界做成镜面湿地。
- 两片折线背景山墙改为连续起伏的远景地形，仅为设计背景，不是实测重庆山体。
- 店主20、骑手09、车辆和订单机制未重做；本轮复查其在新场景中的通行和交互。

## 实景观察与授权

实际在浏览器查看 John Rash 2013-07-22 的重庆阶梯摄影：
https://www.johnrash.com/imported-20110606170757/2013/7/22/report-from-the-river-chongqing.html

观察的是台阶/平台/墙脚关系、防盗窗、附墙设施、晾晒、局部修补与物件使用关系。这是黑白照片，不能声称据此校准了颜色或光照。照片没有进入游戏，没有作为贴图，未假定其具有商用再分发许可。

原有六张用户缺陷图仍在恢复的证据目录。原最终 R15 照片包仍未回收，本次新参考不等于找回旧照片资产。

复用原工程 Poly Haven 的茶桌、塑料椅、盆栽、垃圾桶、垃圾袋、周转筐及材质；原始扫描保留，仅修改实例位置和低处支撑顶点。新下载 Greg Zaal 的 Kloofendal Overcast (Pure Sky) 2K HDR，来源和许可均在官网确认 CC0，可商用、无需强制署名，仍保留作者。此天空拍摄地不是重庆，作为艺术光照环境使用。文件 MD5 与提供方元数据一致，SHA256记录在 PROVENANCE.json。

许可与逐文件哈希：`assets/street_r19/PROVENANCE.json`；天空原包记录：`work/assets_incoming/r19_sky/PROVENANCE.json`。既有 100STYLE、Rocketbox、OFL、OSM 等许可没有被 CC0 声明覆盖。

## 已实际淘汰的版本

- 程序阴天初稿过灰；强环境能量的摄影阴天初稿又过曝发白，均保留原图。
- 第一版排烟管遮住窗户/店招，第二版移至边缘并补弯头；灯具穿过雨棚，已向下改位并接支架。
- 第一版餐桌挨着垃圾，已移动垃圾组；不能以堆物件数量代替生活感。
- 石质踏步贴图呈细碎地砖感，已换回灰色混凝土、独立分缝和小倒角。
- SDFGI 0.5m、16条射线、300帧稳定试验在窗框/屋檐出现明显黑点/条纹，未纳入默认方案。SSR、反射探针、SDFGI 仍关闭，不能声称实现完整的物理全局光照。
- 扫描椅只按整体最低点落地不足以保证四腿接触，已逐支撑修正；7件实例共28个支撑分区分别检查。

## 继续迭代的主要缺口

大片空旷坡面、建筑重复、统一店招与栏杆形式、玻璃/墙皮和雨水使用痕迹仍显程序化。生活物件已有初步组织，但缺真实营业活动、行人使用、环境声音与动态痕迹。几件近景新增物件不能代表200×200米全区精修；人物和电瓶车也仍有前轮记录的美术缺口。

下一步应先改善主路线两侧的实际平台、门前空间和建筑差异，建立第二段连续高质量街巷；再逐区推进材质层次和稳定的间接光照方案。所有新增物件继续检查入口、净高、排水与支撑，保留可玩的取餐—驾驶—步行送达路线。不能仅加滤镜、雾或暗角来宣称电影级。
