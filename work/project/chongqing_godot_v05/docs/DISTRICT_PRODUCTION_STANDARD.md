# 梯坎里街区制作规范

## 住宅公共空间与送餐 · 一单元实践

先用真实的两处街面标高选址，再定门槛、每级踏高、楼层和外廊落点。单元地址和住户地址在游戏中各有空间含义。门牌贴在门或门楣上，交互点对准可见门板、托架或搁板，按楼层与视线筛选。分开检查玩家脚下碰撞、步行者头肩范围内的装饰、门外树冠，以及反向进楼时看见的旧立面零件。拆除旧阳台要成组处理木栏、托撑、花盆、空调和固定件。两股楼梯接休息平台时，使用连续墙裙和顶板；楼面与平台沿共享边接合。保留双向实走与玩家高度的回看画面。[一单元应用记录](UNIT_DELIVERY_R24.md)

## 复核坡口与路肩 · 本轮实践

先沿真实车轮路线量坡脚、平台与道路外沿，再重建连续横断面。停车处用轮胎校准本地坡度；远处按地形的大尺度起伏渐接。沿接头两侧以相同间距复测高差和行进方向的坡度变化。挡土与通行分别给出可见的构造。重新分配地表时，把跨网格接缝的两侧放到同一套铺砖尺度和材质上，照顾低角度斜光。审批前保留每次失败的断面和原位截图。[构建 21 实例](TERRACE_GARDENS_R24_REVIEW.md)

## 全街区道路复查

在同一张平面图上区分桥面、桥下、地下投影和真实入口。每条可行路量中心及两侧，接头再量横断面。上坡和下坡分别用同一辆玩家车走过。删旧路时一起检查旧路基、两侧路缘、下伏地形和旧装饰的碰撞。收边时以两张真实网格的交线裁切，给改道的小巷留出车把宽度。用玩家眼高斜看灰缝、地面拼纹和远处的分隔带；通行结果和近景、远景观察分别记录。[整区复查实例](DISTRICT_AGE_R24_REVIEW.md)

## 公共坡面和楼梯口的复核

远看一条线、车能通过，都不能单独证明接头合格。先查同一位置所有可见顶面、侧沿和碰撞，再沿两侧按横断面量高，复查真实车轮经过的位置。球场横巷本轮移除了整张覆盖板和包边，在保留的地面上画出使用痕迹。硬质杂物还要比对画面：原先的红椅和箱子没有拦下物理车身，实际画面依然穿帮。桥梁、挡墙和有明确高差的台阶单独检查承托关系。[构建 19 的工程记录](FIRST_SHIFT.md)

适用范围是这座 200 × 200 米的可步行、可骑行街区。主尺度为米。几何、通行和证据要求从本轮起执行。玩家明确驳回了旧版面馆的美术方向。各店的陈设、色调和住宅生活感须经实景对照和玩家实走确认后，才能列为其他街区的样板。

## 一、城市规划先确定街道怎样被人使用

建街之前画一张带标高的平剖图。标出主路车行线、人行带、上院与下院、挡墙、楼梯口、店面出入口，以及送餐员停车、取餐、掉头的位置。每个节点记录走向、净宽、接入标高和两侧用地。把店前排队、临时卸货、居民坐靠和球场出入口画进同一张图，再摆家具。上坡开店时以实际门前铺面定首层，住宅沿坡分入口或退台，避免用一条水平底板吃掉整排首层。

路网和远景白模用于组织朝向、街宽、天际线与遮挡。到一层门头、路肩、院坝的近景必须单独做剖面和通行检查。重庆连续坡地的街道可以左右不对称。明确高差由哪道坎或哪段坡消化。南区路的反例是低位人行带和上院各自放坡，到中段形成长凹槽，走到端头还能看到天空。重建时先定连续横断面，再切掉被接管的原路和地形。

行人路线连到真实目的地。上学、买菜、取餐、休息各有落点；让行人能进入、停留和离开。近处查脚底和开门空间，中距离查行人与车流如何错开，远处查居民总量与时段。车辆分向沿本车道采样，在路口、停靠和折返点单独验轮胎与路面。桥面护栏、球场围网与玩家要求去掉的梯段扶手各自归到所属设施。

## 二、建模要能说清每一件东西靠什么支撑

| 构件 | 建模时必须交代 | 现场验收 |
|---|---|---|
| 雨棚、晾杆、电线 | 雨棚有板厚、檐口和接到墙或柱的端部；电线的两个端点落在相应墙夹、绝缘件或杆上；织物有夹点、重量与折边 | 从棚下回头和从楼上俯看，同一顶面两侧连续；沿电线找到两端；布面近看有织纹与弯折 |
| 桌椅、货箱、电瓶车 | 定义脚底、箱底或前后轮接地点。先测底部各支点；坡度不兼容时调整朝向、移到同一平台或建真实基座。下层箱落地，上层箱落在下层箱上 | 低角度检查四脚与轮胎；物体没有跨在两级铺装上；车停、起步与转向后复量 |
| 窗框、檐口、外机和电表箱 | 墙体开孔或承托，窗有洞口厚度、窗台和回边；外挂件有背板、支架与管线去向 | 贴墙斜看，孔边不透天、设备不嵌进窗扇；管道末端抵达排水或服务位置 |
| 篮板、围网和观众座 | 篮板标线在同一面上完整闭合；网片落在立柱、底座与顶横梁之间。座椅前向由使用对象决定 | 从球员、球后行人和坐席三个方向检查。本站西侧两把座椅面向球场中心，两端加高网片保留原网孔尺度 |
| 排水口、花坛和树池 | 井框四角落在同一有效坡面，切出实际井腔；树池与花坛由一个外边界控制砖口，种植土与路面有交代 | 踏面、过街路线和转角净空内无误布的箅条。砖边相遇时截断或合并，井箅看到框、下横撑和井底 |

重复道具要记录所属表面、朝向与支点。水平射线能确认背板进墙，下探能确认脚底。仅对中心点落地会让长椅另一头悬空；把所有东西压低会使箱脚与轮胎埋进地面。共用材质批次中的独立部件应整件移动、整件退役，避免只移动瓶子留下盖子，或只去掉一排箅条留下井框。

## 三、拼接由一套边界同时生成顶面、侧面和碰撞

1. 确定谁管理这个空间。记录旧顶面、路边条、装饰鼻口、挡墙、地基、碰撞和编辑器预览各自的来源。关闭一个渲染层后，仍要检查底下旧面和旧碰撞。
2. 在平面上定接缝和每个顶点的标高。主路、支路、两段梯跑的首末级与转弯平台共用边线。急转可设合理平台或设计扇形踏步。旧的两段直梯分别以矩形收尾曾在转角留下三角缺口。
3. 沿所占范围切开原地形和下层旧铺面。完成踏步立面、侧面、坡肩和端部封口。挡墙上口跟上层，下口接实下层；闭合处法线、厚度、切线与导出后三角划分一致。在源文件里同时看剖面和单面显示。
4. 同一种铺装约定实物尺寸、铺向和起缝点。转角从同一排砖展开，墙脚、门槛与井框周边允许真实裁砖；材料改变时用现实的收边方式交代。不用额外一层同高贴片掩盖缝隙。纹理方向、粗糙度和法线在放大和缩小后都要读得通。
5. 在 Godot 同时测真实玩家碰撞和可见表面。对坡肩西端这次漏检的白三角，垂直下探与往返步行事实上都能通过；从玩家截图的像素发斜射线却穿出城区。以后接头都要有迎坡、背坡、侧向和贴边低机位，复测原图箭头处及其两侧。保留失败像素和碰撞对象名称。

## 四、建筑美术按开间和用途组织空间

先定从街边到门槛、待客区、服务区再到后墙的净深和高差。街边横移时，门框应依次遮住近处陈设和后墙。量门洞两边及中线的实际深度，同时检查前一天的碰撞壳、旧瓷片墙和邻户空间。玻璃反射强度、窗帘开幅和前后明暗共同服务于观看；住宅之间应有遮挡与隐私差异。只有空箱子加一张后墙仍不构成可读的内室。

下厨房前先演一遍工序。用锅、捞面、调碗、递出、吃完回收，应顺手并各有支撑。面馆后场的锅在灶口，烟罩、烟管和墙洞连成一条；洗池内有盆底、水嘴及可站立位置；碗架带托臂，釉碗能嵌叠。门口短暂停留区给取餐人留脚步，前台一侧留出到后场的通道。菜单字在玩家眼高可读，同一信息不在几块装饰牌上重复。住宅、修理铺、菜摊不能直接整套复制面馆布置。

## 五、空间美术以街边实物校准材质与使用痕迹

本轮以梯坎面与小唐面庄的门口照片核对开放灶台、使用中的器具和矮凳，以重庆晨报的现场记录核对围墙、梯坎和吃面位置的关系。三者代表具体店铺，不能推为全重庆的统一风格。[梯坎面门面照片](https://hk.trip.com/restaurant/china/chongqing/detail/restaurant-11570749/) · [小唐面庄实拍](https://touch.travel.qunar.com/comment/10141207216) · [重庆晨报现场报道](https://epaper.cqcb.com/html/202401/04/content_443423.html)

- 每处重点门面准备整体、中景操作和近景接触三张对照。先比桌椅尺度、锅碗密度、室内外明暗，再比配色。旧面馆被退回时，中轴红牌、双吊灯、木条柜和茶具同时出现，门外几乎看不出煮面与取餐的分工。更换单个锅或给后墙再加一排架子，都无法解决整间店的陈设逻辑。
- 钢板应能反射店内暗部，并在折边和磨痕上出现窄亮边；油锅口、碗釉、竹筷、塑料凳和地砖在同一灯光下要读作不同材质。用尺度正确的表面细节、圆边和局部遮挡消除灰色剪纸感。灯具的位置要对应案板、灶口或门口，暗处应有层次。
- 磨损有位置和成因。锅边会擦亮，旧砖在接缝与墙脚积灰，水池周边受潮，常走位置抛光，桌边掉漆，墙上留有曾经固定挂件的小孔。先做一处有因果的使用痕迹，再检查近处、中距离和运动中是否成立。全街统一加灰、统一做旧或四处散落垃圾都会失真。
- 生活感来自动作留下的布置。够得到的调料、正被用的凳、窗边晾晒、避开通行线的货筐，比沿路等距摆居民和盆栽更可信。角色暂时走开后，场所用途仍然应该能看懂。街坊各自使用空间的方式不同，保留空处、门口作业处和通行处的差别。

## 六、进入下一轮之前留下什么

| 环节 | 应保存的证据 | 退回条件 |
|---|---|---|
| 定位 | 玩家原图、机位、箭头像素、实际物件名、可重走路线 | 只能给相似街景截图，无法指认玩家所说的位置 |
| 源文件 | 独立可重开的整城源、上次基线、分层资产、材质/照片来源及变更清单 | 丢可编辑源、同名重贴旧文件、资产许可或作者缺失 |
| 原生导入 | 指定版本 Blender 与 Godot，重新导入并打开实际主场景，检查默认项目与编辑器预览 | 只有离线渲染，或机位靠候选参数才能看到而默认游戏仍是旧版 |
| 试玩 | 人眼高度同机位原图、反向视图、连续步行/骑行记录、接触点检查、取送餐回归、同路线成对帧时 | 只测中心、不测边；只跑脚本、不看图；只截好看的角度；帧时负载和对照不同却宣称更快 |
| 记录 | 逐项写明已修改、导入、实际执行、画面复看和仍未验证的范围。保留失败结果 | 把一次通过推广成整城验收，或把当前内部试做当作玩家认可的样板 |

复发时先补能复现原问题的检查，再修生成源和同类位置。原始截图、可重现场景、精确候选、原生帧与检查结果应能互相找到。发行权利未明确的城市模型继续沿用既有用途限制；实拍参考图在本轮只供观察，自制游戏表面与外部照片分开登记。
