    100STYLE

    This is the 100STYLE dataset, it contains over 4 million frames of motion capture data for 100 different styles of locomotion.

    Download the 100STYLE dataset (Zenodo)

    Download the 100STYLE dataset - BVH only (Google Drive)

    Retargeted to a skinned character - FBX & BVH (by Daniel Holden)

    Dataset Information

    For each style, one actor captures: forwards walking and running movements; backwards walking and running movements; sidestep walking and running movements; idling movements; and transitions between movements. The actor is the same for all styles.

    Unedited BVH files are provided for each type of movement and each style. Individual files can be downloaded from the table at the bottom of the page. The files are named in the format <StyleName>_<MovementType>.bvh. The movement type abbreviations are detailed in the table below. Some styles have multiple files capturing transitions.

    MovementType Movements
    BR Backwards Running
    BW Backwards Walking
    FR Forwards Running
    FW Forwards Walking
    ID Idling
    SR Sidestep Running
    SW Sidestep Walking
    TR1/TR2/TR3 Transitions
    Further Details The BVH files are exported from motion capture sessions performed using an XSens motion capture system and are captured at 60 fps. Stylised movements begin and end with T-poses but there are some additional leading and tailing frames before and after the T-poses. We provide Frame_Cuts.csv, which gives the beginning and end frame indices to trim to in order to remove these unnecessary motions (and the T-poses). We also provide Dataset_List.csv, which gives a full list of styles and may be used for automatic filtering and mirroring of styles. The data uses a 28 bone skeleton, with the hierearchy shown below. Users are free to use this information to extract and process the data however they wish.
