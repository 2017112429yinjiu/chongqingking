# 金马寺小学旧址 · 山城故事馆一楼

这次做的是原校舍一楼的一间教室。玩家从校门进来，从拼桌与窗下课桌之间走到馆名横匾前，再绕过板凳，经玻璃高柜一侧的门去楼梯。站在梯脚转身，能隔着真实门框看见中央的长桌和窗边的收录机。[门口至楼梯的连续实走](evidence/door_to_stair.mp4) · [梯脚回望](evidence/look_back.jpg)

## 实景怎样对应到模型

| 在同址照片上看到的关系 | 游戏中的落位与做法 |
| --- | --- |
| 馆名横匾下，一侧是格柜，另一侧是面向访客的书刊架。格柜顶有义卖牌和折叠的浅色布袋。 | 横匾、标识和册页分别绘制。格柜能看见板厚、背板、叠册和布袋。斜架逐层立放书刊，下沿挡条托住封面。 |
| 靠窗的几张旧桌组成器物展台。方形木框玻璃小展柜在唱机靠墙角的一端，另一端是黄色双喇叭收录机、小收录机和绿台灯。 | 把柜脚落在桌面内侧，模型可见四面玻璃、底板和柜内器物。唱机有唱盘、唱针臂、铰接式箱盖和锁扣。收录机有喇叭网、刻度盘、按键、磁带窗和提手。 |
| 窗柱旁另有覆粉色布的小台。公交售票盒打开，金属票夹固定在盖内，下半盒放散票。 | 单独做了曲腿木台、垂边带流苏的台布、盒口卷边、铰链、提手、夹票和盒底的票据。 |
| 访客中间的深色长桌由较短的桌子拼成，沿桌是窄板凳，桌面放浅印章盘；反向照片能看到门洞之间的玻璃高柜。 | 长桌保留拼缝、桌裙、收细的木腿和木纹。高柜有下柜、门梃、拉手和可透视的分层陈列。两组门洞连回原来的楼梯通道。 |

两组照片交叉确认了上述前后、相邻和对向关系。公开资料未给出室内测绘图，游戏按校舍已登记的楼体、现有窗跨和楼梯拟合了教室位置、过道宽度和家具尺寸。纸张上的票面、封面和留言表是游戏自绘示意。柜内难以辨认的小件按可见轮廓近似，只有孤立近照、缺乏陈列位置的电话没有摆入。照片版权保留在原出处。[馆方志愿者双向全景](https://www.meipian.cn/4h4zwp4k) · [《重庆晚报》室内全景与器物近照](https://finance.sina.com.cn/tech/roll/2023-02-01/doc-imyeeens9958577.shtml) · [逐图用途、原始哈希、木纹与字体授权](sources.json)

## 从门口走到楼梯，再回头

在独立试作工程的 Godot 4.6.3 Forward+ 常规入口 `first_shift.tscn` 启动 500 米街区。玩家从校门外起步，走到单独的售票盒小台前，转头看票盒；继续经过收录机和唱机，到端部格柜前停下，再从长桌另一侧出门，走到第一跑楼梯脚。三段合计 18.52 米，12 个沿途目标全部到达。回头转了 156.09°，脚下位移为 0 米。录像保留玩家界面，按每 9 个物理帧取一帧记录。同机位对照和展品近景另行拍摄。[实走录像](evidence/door_to_stair.mp4) · [实走数值](evidence/walk.json) · [楼梯脚玩家视角](evidence/look_back.jpg)

Blender 4.3.2 重开校舍源文件与引用该源文件的整区场景。实测拼桌面高 0.769 米、凳面高 0.429 米，八只长桌脚接地，小玻璃柜四角都有旧课桌承托。Godot 内重走了取件、送单、前后门及二楼楼梯，复查地面和上层书架。保存了票盒摆位、局部照明过曝和台布穿模的中间画面。[源文件与游戏检查](evidence/inspection.json) · [中间失败画面](evidence/iterations.jpg) · [原街区路网巡检](evidence/patrol.json)

另用同一入口单独采样格柜、窗边课桌和梯脚三个视角，每处 150 帧。RTX 4070 Laptop GPU 的窗口为 1152 × 648，采样时内部视口为 692 × 389。各视角的 GPU 中位数、95 分位数和墙钟耗时见检查记录。

## 复跑

校舍源文件是 [delivery_courts.blend](../delivery_courts.blend)。[room.py](room.py) 包含课桌、柜与楼内窗跨的相对落位。[printwork.py](printwork.py) 用项目已有 Noto 字体生成印刷图集，依赖 Pillow、NumPy。运行 [architecture.py](../architecture.py) 时打开上游 `district_500/outer_district.blend`；它同时保存可编辑的校舍和 Godot 导入用的 `historic_courts.glb`。项目导入时将两束教室轨道灯适配到现有的相对灯光单位。

从仓库根目录执行，输出与用户数据路径需使用新目录。Godot 和 Blender 可传入本机对应版本的可执行文件路径。

```text
python work/scene_r24/shancheng_courts/verify.py --capture --godot godot --blender blender --output <fresh-output> --user-data <fresh-user-data>
```
