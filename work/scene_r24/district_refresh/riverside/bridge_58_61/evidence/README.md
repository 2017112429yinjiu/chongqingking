普通玩家从长滨路公园侧步行带出发，步行经 57 园口、轨道梁下、公园步道、车库外侧观察点和 61 园边，原路返回。去程 **219.454 米**，回程 **218.423 米**，两腿各 **42/42** 路点，无途中重置或卡点。路程最近处仍在登记车道轴线外约 6.47 米。四处停靠坐标、最近距、逐帧抽样和真实柱状碰撞留在原记录。 [横断面和到访](measured-sections-and-visits.json) · [Godot 走测](round-trip.json) · [桥下到车库](bridge-and-parking-from-park.png) · [园路玩家回望](player-look-back.png)

保留两张首轮候选返图。初版车库贴路遮圆柱，轨道梁近江端在远处被截断。最终将沿街车库前缘退到柱后，河面使用独立的开放轴线背景轨道续段。 [58 首轮](first-fit-58.png) · [59 首轮](first-fit-59.png)
