## 运行与重建

使用 Blender 4.3.2 打开原城区源，再运行 `build.py` 导出独立的 `park-plot61.blend`、`park-plot61.glb` 和场景清单。对组合城运行 `ray_check.py`，对组合城与独立增量运行 `check_source.py`。

默认 `first_shift.tscn` 加载新版。可通过 `work/scene_r24/district_500/play.sh --software -- --explore-500 --park-61` 从长滨路公园侧步行带开局。用 Godot 4.6.3 和新的 `CQ_QA_DIR` 执行本目录 `walk.gd`，参数为 `--day-one-test --explore-500 --park-61`。 [引擎实走、原生图和回归](evidence)
