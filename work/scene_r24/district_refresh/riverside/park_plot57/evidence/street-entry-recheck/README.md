# 57 号相邻园门三机位复查

对照 `52031ffe` 的登记机位。街边改前图来自本轮父版 `4dcc4895`，其中旧 57 已撤、蓝场缝已封。另用原桥西挡墙替换组合城里的同名网格，单独对照这次改的墙段。在 Blender 4.3.2 重开独立源与组合城，共测 40 个登记像素。 [原机位](../../../west_ramp/evidence/summary.json) · [光线、墙脚断面与重开结果](blender-pixels-and-ground.json)

| 机位 | 实测所见 |
| --- | --- |
| 浅砂区回望 | 深色矩形命中带灰石贴图的挡墙正面。几个代表断面的高、低两侧都接到有效地表，暗面保留。原图后方单独命中旧 57 楼身的像素随旧楼撤去。 [原始图](../../../west_ramp/evidence/sand-return-look.png) · [本轮原生图](sand-return-after.png) |
| 长滨路回望 | (749,371) 命中旧石墙背面。该段约 0.71 米，两侧铺地在接缝处高差 2–4 厘米，旧面西段却仍高出约 1.46 米。沿两个铺地高程重新收边，保留转角后仍承托高地的墙。改后这条视线落到铺地。 [改前原生图](street-return-before.png) · [改后原生图](street-return-after.png) |
| 蓝场后缘 | 原图三个亮缝像素穿空。原约 0.40 米宽的缺口已封，本轮三条原射线仍全中有贴图的端面，Godot 五个高度均命中封端碰撞。 [原始图](../../../west_ramp/evidence/blue-after.png) · [本轮原生图](blue-after.png) |

Godot 4.6.3 从正常 `first_shift.tscn` 的长滨路公园侧步行带出发。旧墙在 12.055 米处卡住角色，只到 5/7 个路点。新接头三处横断面均命中低石边，地面以上 0.24 米及 0.90 米的六条射线全部通畅，走完 7/7 个路点后原路返回。实走 13.748 米和 13.698 米，无卡点。 [旧墙碰撞](joint-before.json) · [新接头双向走测](joint-after.json)

57 号原路线双向各达到 17/17 个路点，去回 60.736／60.094 米。长滨路到浅砂区往返 27.569／27.595 米，园路到浅砂区往返 60.766／60.858 米。 [57 号原生往返](native-after.json) · [长滨路到浅砂区](regression-street-to-sand.json) · [园路到浅砂区](regression-park-route-to-sand.json)

原生帧沿用登记视角和无日照投影设置，在 Xvfb 下用 Godot Compatibility、Mesa llvmpipe 采集。退出时记录了两条 GL 纹理回收告警，截图已保存且测试退出码为 0。
