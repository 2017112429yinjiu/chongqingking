# 55 号长滨路公园侧街肩

原试作住宅中心 E−142.55／N−157.48，原足迹被长江滨江路 59146737 中线穿过 10.44 米。北向图在这片范围可辨车道、缘石、连续公园侧步面、下方浅色游乐区与蓝场。2020 同址街景见路边护栏、树与施工中的轨道桥。2023 完工斜照可区分同址轨道、立交匝道和下方独立园路。使用开口和道路边界作平面参照，游戏高程继承原正常场景。 [逐项登记](field.json) · [既有街边开口](../west_ramp/README.md)

撤下旧 55 号楼框、附属楼梯和相关碰撞。从既有 E−158.97／N−159.07 公园侧街边接长灰石步带和沿道路的矮缘石，保留开口去浅砂区的支路。街肩与开口共用原公园承面的覆盖资料。使用项目原已有的石材与磨损纹理。 [原生图与路线](evidence/README.md)

用 Blender 4.3.2 以 CQ_CHANGBIN_55_PARENT=1 重组已合入 04／06／51 的父版，打开组合后执行 `build.py -- 导出目录`。`CQ_ROADSIDE55_SOURCE` 可指定独立 Blender 源路径。将增量 GLB、JSON 置于 Godot 的 `assets/district_500`。用 `check_source.py` 重开独立及组合源。Godot 4.6.3 正常试玩参数 `--explore-500 --changbin-55-park`，站在街肩东端。`walk.gd` 使用正常探索玩家，沿灰石步带走至已有园门，下到浅砂区，原地回身回到同一处街肩。固定图采用本目录 `views.json`。
