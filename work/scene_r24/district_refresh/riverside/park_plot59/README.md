# 滨江公园 59 号浅砂区

在桥梁批 `23a4566a` 上单独更新 59 号。按原 OSM 控制把旧旋转轮廓投回两期 Wayback 影像，并以西侧园路折角、白墩脚、浅砂外角与东侧球场校对龙帆 2023-10-25 原片。原片第 1 页第二张内嵌图是 1969 × 1143 像素。59 中心约落在 (1687,716)，留一配准区间落在浅砂、浅蓝折线硬铺和草带的交界附近。已核过的 2024、2025 影像也直接显示折角铺地和浅砂跨过旧楼范围。照片只作为观察材料，像素保存在云端参考目录。 [地图、来源日期、原图指纹与配准](field-controls.json) · [重庆日报原页](https://epaper.cqrb.cn/cqrb/2023-10/26/004/cqrb20231026004.pdf)

撤去 59 原独栋、门窗、室内地面和附属碰撞。共享外壳、路边与陈设按逐面指纹归属移除 603 面。原位置接成浅砂场、折线灰铺、浅蓝硬地与灰砖石树池广场。折线路接回长滨路公园侧步行带与桥下东西园路。灰砖压边、窄草带与两个有实体收边的树池分别成形。坡面使用周边现有有效地形，表面 UV 复用项目既有许可材质。铺砖间距与树池精确位置按游戏拟合，树后小设施用途待核。 [源文件](park-plot59.blend) · [实测与原生图](evidence)

61 另作同尺度叠框，以本身的 130° 机位和原报纸图约 (1665,616) 点复查。两期影像中 61 中心都在连续冠层内，瓦片只见到外围铺地碎片。街景沿前景树列和施工围挡，斜照还有梁遮挡。现地铺地类型、是否有低设施及楼位待核，保留 61 的旧试作房体及记录。规划文书能核全园设施类型，无法给出 61 的门牌或屋角。 [61 单独复核](evidence/plot61-observation.json) · [区住建委复函](https://www.cqyz.gov.cn/zwgk_229/jytabl/zxwytabl/202206/t20220609_10791342.html)

## 运行和重建

用 Blender 4.3.2 打开 `../../../district_500/outer_district.blend` 再执行 `build.py`。用 `check_source.py` 重开独立源和组合城。增量导出位于原 Godot 工程 `assets/district_500/park-plot59.glb` 和同名 JSON。

Godot 4.6.3 在正常 `first_shift.tscn` 自动加载。试玩可以运行 `work/scene_r24/district_500/play.sh --software -- --explore-500 --park-59`，开局在长滨路公园侧人行带。走测执行本目录 `walk.gd`，使用独立 `CQ_QA_DIR` 与同一开局参数。加 `--qa-without-park-plot59` 回看桥梁批的原 59 形态。
