# 城区逐地块及原 200 米接头记录

`plots.tsv` 为带 BOM 的 UTF-8 制表符文件。按旧地块编号排 00–77，覆盖原 `layout.json` 的 71 个旧地块，另有 7 个既有撤回或飞越保留编号。核心区继续使用 A03、A04、一单元 202 和 301、仁爱堂、金马寺小学等既有标识。表末单列 7 个原 200 米与外区接头，按原接头记录名称和同一 EN 坐标。

地图列注明可支撑定位的开放道路、楼体轮廓或邻近地图对象。邻近关系、航片观察和游戏地表高度各用自己的描述。可用的同址影像只登记可辨认的体量、出入口、材料或空间关系。凉亭子图 3 的路口候选配准留一误差 4.39–29.81 米。图 4 的单元外观、陈设和门槛需有独立的同址定位。历史远景按既有权利用途登记。公开地图保持 OpenStreetMap 的 ODbL 1.0 归属，62 号的开放建筑轮廓另用 Shi 等 CC BY 4.0 数据。

表中原场景、正式替换及独立试件的状态对应各自的实测记录。行走栏包括保留的失败、步行控制器两向结果以及试验阶段。部分在用住宅玩法内装没有公开的现场依据，按玩法制作登记。当前阶段的市场裙房、43/44 邻接、滨江 62 号和桥西坡侧试件另见 `field-follow-up.json`，它与云端逐项原始输出相连。

`core-entry-stations.json` 保存七个接头的地图对象、原高度与路径采样，正南为贴合既有地势的游戏设计连接。Godot 4.6.3 以 60 Hz 在正常 `first_shift.tscn` 下复跑。直接下脚走东侧中兴路中心时，去、回均碰到自由探索的默认停车电瓶车。保留 `core-entry-centreline-walk.json`。`core-entry-walk.json` 记录同一接头经已有路肩绕车的两向，以及其余六处各两向。该次经过保留的停车环境，14 段通过。七处各 325 个断面采样，合计 2,275 点。断面基础数据来自随国浩批保存的区内回归。

在 `guoco-low-street-24-25.json` 中登记旧 24/25 号和开放路网的实际交叠。两份政府资料分别确认地面路网移交、凤凰台街与解放西路交叉口至国浩车库的道路关系。同址照片仍需分别核对旧占位的身份、所在层位和实际边界。`guoco-legacy-low-frontage-walk.json` 保留两条早期路线的现版本复跑，包括与楼体发生碰撞的路线。国浩第三版已通过的公共路线见相邻街组的 `guoco/evidence/results.json`。

表内 `district_refresh/`、`shancheng_courts/` 等路径相对 `work/scene_r24/`。`patched/`、`street-groups/` 和 `core200-linux-20261126/` 指向原云端 `/workspace/work/runtime/district-refresh/` 中的历史或试件记录。当前已交接国浩制作提交为 `7efc86c1d45c9c0a7f3e666cc495cac05f6dc6e4`。
