# 花池实走与原生对照

三侧实际往返 18.203/18.101m，两向12/12；新露高0.490–0.610m。 使用正常第一班场景的玩家控制器，每次循西侧、前缘、东侧并原地折返。去程26/26和回程25/25采样均命中新增公共铺地。48点逐个确认盖石、池身在地面以上30毫米处有连续碰撞、石墙根埋在铺地下。第一轮东侧踩上盖石的运动记录保留。

远处近黑多边形回射到围外的旧建筑基座及相邻原坡。近景留有黑灰实石触感，并可看到三脚树撑、收边和灰铺料缝。西侧原版坡坎改为顺旧街边的变坡收面。

原生帧由 Godot 4.6.3 OpenGL Compatibility、Mesa llvmpipe 导出，900×560。定机位不放置玩家到现场，现场玩家转身帧另存。两组四个相机矩阵一致。Blender 4.3.2 独立增量与链接组合均重新打开并量取接触。
