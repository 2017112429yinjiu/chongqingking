# 中兴路收藏品市场高侧入口

中兴路 75 号市场由下回水沟 1、7 号的共同裙房经营。以中兴路 way 176034707、公交站 node 11049229719 和住宅 way 809889619／809889620 为控制。两处住宅外轮廓分开登记。809889619 有实名，809889620 是位置相符的候选住宅轮廓。西侧 40.85 米裙房正面贴游戏原地面，重做赤色砖、灰白压顶、窗框、金属百叶、退进的正门及灰块石踏步。住宅体量沿开放轮廓落地，以浅灰面、凸阳台和深窗作远近对读。住宅层数、裙房后界和绝对高度目前采用游戏设定。[中兴路](https://www.openstreetmap.org/way/176034707) · [公交站](https://www.openstreetmap.org/node/11049229719) · [住宅 1](https://www.openstreetmap.org/way/809889619) · [相邻住宅轮廓](https://www.openstreetmap.org/way/809889620)

临街两张实景能辨认标牌、入口临路高差、砖柱浅色柱头、窗和深色店面。2020 年走访记录从中兴路进门是四楼家电区，也记有旧书、集邮及其他分区。门内按旧货店用途制作可通行的水泥地小厅、梁柱、灯管、展示柜和旧电器模形。室内尺寸、货架位置和侧开口是游戏布局。08、09 旧占位与新厅及正面设计轮廓分别平面交叠约 40.96、29.13 平方米，撤去相交旧楼和它们的普通玩法房。11 号不与本次的改动轮廓相交，仍单独待核。[公交站旁实景](https://lbsugc.cdn.bcebos.com/images/B65dc22467b1d52d82.jpeg) · [入口侧面实景](https://poi-pic-gz.cdn.bcebos.com/pic_1ba99e99b7c9d83296b72a8dbf1329af.jpeg) · [市场内部采访](https://m.thepaper.cn/newsDetail_forward_9057120)

地上停车场出入口 UID f6acf5d1b26bbb7984330486 在 E287.652／N167.043，东出 500 米边界 37.652 米。场内点 062367e5f4a562083010afbc 在 E285.811／N194.422。两条目共享照片，能对读浅灰水泥、窄网格砖步带、路缘、深灰石挡墙和方孔矮栏。侧向通道使用这些铺地和收边线索。停车场和商务委所述车库洞口分别登记。凤凰台街侧车库洞口、停车场到西侧裙房的精确步行连接及高程仍待现场定位。[停车场同址实拍](https://taojin-pic-bj.cdn.bcebos.com/bf2b5c29eb307fbe48b150ccec5aa1da.jpeg) · [区商务委答复](https://www.cqyz.gov.cn/zwgk_229/jytabl/rddbjy/202506/t20250627_14754277.html)

## 制作和连续实走

Blender 4.3.2 打开 `work/scene_r24/district_500/outer_district.blend` 后执行同组 `build.py`。它读取本组逐面归属和已发布供体，输出独立源、GLB 及路线。正门牌使用 `build_sign_font.py` 从 Noto Sans CJK SC 缩编并改名，沿用项目内完整 OFL 文本。实拍只用于观察，照片像素未作为资产分发。

在 Godot 4.6.3 正常 `first_shift.tscn` 使用 `--explore-500 --zhongxing-collectibles` 从中兴路东侧路肩开局。同组 `walk.gd` 用正常探索开局位置、同一个玩家身体和控制器走进、转头、原路走回；两段之间零位置重置。按表中开放地标出发点保持相同，可以用 `--qa-without-collectibles` 复跑改前。侧阶路线用 `--qa-market-side`。原始轨迹、停滞接触和渲染条件随证据记录。场景内的门槛标高和步数均为游戏实测值。

## 第二轮室内和入口复查

按同址的「中兴路旧货市场内的店铺」和「人们搬空调」对照灰绿分格露骨料、吊管和支座、灯管、带网罩的旧电器、灰石踏步、砖墙台端及路肩。独立源重做凹入洗衣机舷窗、风扇网罩、空调格栅和叶轮、CRT 弧形玻璃、音响及成摞 DVD 机，加入开放层架和薄框玻璃柜，保留主厅以及通向侧阶的走道。[采访图与照片指纹](art-controls.json) · [市场走访](https://m.thepaper.cn/newsDetail_forward_9057120)

器具型号、数量和摆位按玩法拟合。每件的朝向、尺寸和底部 ENU 坐标见游戏 `assets/district_500/collectibles-market.json` 的 `interior_art.inventory`。入口加了分块石鼻、门轨、铺地收口和小排水带，原阶高、门槛与碰撞承面保留。灰绿水磨石按约 0.95 米分格，墙上磨损面和贴图沿用既有许可；正常 Godot 导入测了每个地面材质、墙面 UV 和启用的法线图。
