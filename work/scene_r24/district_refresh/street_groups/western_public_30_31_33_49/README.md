# 西坡公共铺带与剩余地块复核

在正常场景用 `--explore-500 --north-edge=30`、`31`、`33` 或 `49` 进入。园侧入口用 `--north-edge=30-garden` 和 `--north-edge=31-garden`。25 外部门面另见 [解放西路大阶](../jiefang_gate25_finish/README.md)，同一候选包括这两层制作。

西坡地图图幅按可见道合图和 OSM 734116600 近似配准，拟合 RMS 2.08m，单点留一偏差最大 5.81m。仁爱堂主楼酒店标点只是范围核对，没用作屋角。2025 L 形实拍只作观察，图像和地名的出处登记在 [field.json](field.json)。

Blender 4.3.2 用 `CQ_WESTERN_PUBLIC_PARENT=1` 生成组合父源，运行本目录 `build.py -- <输出目录>`。取消变量后组合接入。Godot 4.6.3 运行 `walk.gd`，另用 `market_return_01.gd --explore-500 --outer-market` 及 `outside_52.gd` 记录。来源照不随试作发布。 灰铺沿公缘和原地面渐接。33号的管位按交会落点，延长石墙至远机位可见的墙侧长度，墙体厚度、石块尺度和青苔密度为游戏近似。
