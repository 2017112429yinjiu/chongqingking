用 Blender 4.3.2 先执行 `CQ_JIEFANG_PUBLIC_PARENT=1 blender -b --factory-startup -P work/scene_r24/district_500/compose.py`，再对父组合运行本目录 `build.py -- <输出目录>`。将 GLB 与 JSON 置于 `assets/district_500`，源放本目录。取消父版变量可重新组合。`check_source.py` 可对增量和组合复开。`walk.gd`、`tea_handoff.gd` 和 `ride_underpass.gd` 读取正常第一班场景，记录身体走行和车轮支承。对照原生固定画面由 `--site-fixed-views=<views.json>` 导出，父版加 `--qa-without-jiefang-public-edges`。
