`register_panoramas.py` 读取 sdata 原始 X/Y，依次计算 BD09 Mercator、BD09、GCJ02、WGS84、项目 E/N。沿 way/734116601 项目旧控制投影，比较原近似 E/N 及已固定 OSM 路段版本和距离。数值逆算误差与实际街景定位误差分开。原始照片像素和地图图像只作观察。GLB 的地面和墙面纹理沿用项目 `chongqing_district_*` 已有资产，数据许可沿用项目清单。

用 Blender 4.3.2 从仓库根目录执行 `CQ_NORTH_EDGE_PARENT=1 blender -b --factory-startup -P work/scene_r24/district_500/compose.py`。再打开生成的 `work/scene_r24/district_500/city_and_outer.local.blend`，执行 `--python <本目录>/build.py -- <独立导出目录>`。`CQ_NORTH_EDGES_SOURCE` 可指定单独 `.blend` 保存位置。复制 GLB 和 JSON 到 Godot 的 `assets/district_500`。独立源和组合城用本目录 `check_source.py` 重开复核。再次运行 `compose.py` 时去掉父版参数以链接新区。Godot 4.6.3 完成导入后运行本目录 `walk.gd -- --day-one-test --qa-still-frames`。固定帧另带 `--site-fixed-views=<本目录>/views.json`，父版另加 `--qa-without-north-edges`。
