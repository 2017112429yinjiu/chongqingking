# 01 主厅与 52 两层街景复核

01 的现有市场是游戏地点。2019 街眼距离约 60 米，只能确认周边部分街脚和台阶。保留原建筑轮廓、三层功能、摊主和 201 路线。使用原来的时令菜摊与干货柜台添加一项探索模式托送，正常从街肩进主厅，以 E 取送，再沿来路返回。真实门牌和经营用途继续待证。

52 的 2020 低位照片能识别树坡、车路和上方匝道。2023 高侧照片能核独立步带、花箱、栏杆和车道。旧屋遮挡与候选屋址仍需另一组同址证据。保留原试作建筑及目前开放的外地表。低外坡走线、登记低道路的剖面和 06/51 相邻高步道分别留档，三者之间没有推测性的近地连线。

两版原生截图来自相同的 Godot 4.6.3 OpenGL Compatibility 软件渲染。旧项目执行 47ab8425 的资源和脚本，当前项目沿用 bb91ddda 几何并加入主厅交接。比较时分别输出 Godot 实际 View 和 Projection 矩阵。铺地、楼壳和碰撞在两处的存留直接见现场证据及原始矩阵。

`market_handoff.gd --explore-500 --outer-market` 和 `layers52.gd` 运行正常第一班场景。实走后用 `make_views.py` 读 layout、交接和分层报告，然后在两份项目上分别用 `views.gd --site-fixed-views=<views.json>` 捕获。实景图只用于定位与观察。
