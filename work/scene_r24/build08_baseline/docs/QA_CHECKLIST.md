# R18 骑手与车辆新增检查

- 双手比较手腕目标位置与引擎骨架，直行/转向/倒车都小于2mm；图像另查掌指包住把手，骨点通过不等于全部皮肤无穿透。
- 车轮由真实移动距离转动，刹停不空转；用每轮8个最低橡胶网格点对实际路面求离地距离，允许18mm以内，仅适用于本次路段/姿态。
- 停车左脚先越过踏板边缘再下落，源鞋底在基准平面约3mm，踏板姿态约0.362m。横坡仍待专项拟合。
- 下车后等待物理帧边界，确认步行碰撞恢复、骑手隐藏、脚撑伸出、车辆位移小于2cm。必须保留旧流程约0.7m挤动的回归用例。
- 导出动画起始时间是1/30s，运行时采样必须补偿；关闭该人物动作优化器，记录导入配置哈希。
- 近景、整单、原有交互和独立性能重新跑当前资产。新增骑手不代表已经完成上下车全身表演、存档、群体AI或电影级验收。
