# 山城巷临崖步道 · 0 号修理院

从 [临崖步道](https://www.openstreetmap.org/way/734116598) 上的出生点走上五级浅石阶，穿过雨棚到修理柜台，按 **E** 请师傅检查胎压。电瓶车要停在檐下。通过后门进入有树的三面廊院，可以沿来路回到同一个街口。双击 [进修理院给车充气.cmd](../../进修理院给车充气.cmd) 即可体验。另一个入口 [沿山城巷送一单.cmd](../../沿山城巷送一单.cmd) 仍从原取餐点开始。

已有 Linux 云端检出的试玩入口是 `bash work/scene_r24/district_500/play.sh --software -- --explore-500 --repair-court`，从仓库根目录运行。本批实测来自 Windows 独立克隆。

总图推算临街一排约 32.95 × 9.03 米。两段屋面的外轮廓各自随图落位。楼层高度、窗格细分、室内梁柱和工作台按游戏通行尺度制作。目前照片能定位到这段临崖街面。门牌、修理铺业态、逐窗尺寸及院内石板原样均待现场资料确认。南区路到崖顶的真实绝对高差也待测。修理铺保留为游戏里的服务点。公开提交包含自制模型、原始坐标测读和游戏实拍；外部照片权利归原作者，查阅图像的作者、网址和哈希见 [sources.json](sources.json)。

## 五轮现场检查

| 轮次 | 街上或院内看到的问题 | 下一轮改动 |
| --- | --- | --- |
| 1 | 旧楼旋转后仍有一条贯通两家的雨棚，草坡穿过石阶，后墙过于封闭。 | 收窄修理棚，外侧开木窗，沿五级踏步重新切坡并做侧沟。 |
| 2 | 石阶接顺了，玩家步行高度看去，二层仍接近连续的平墙，院中也缺少总图里的树。 | 两段屋面下分别做外挑木窗廊，在图示树位留树池，木铺地按步道自己的转折放样。 |
| 3 | 街侧木板带从远处看近似路旁平铺，院坝石材与旧街的颜色也偏离。 | 临崖一侧补木扶手和细栏杆，石阶与院坝混用旧工程已有的灰色、暖色铺地；通向院子的台阶保持敞开。 |
| 4 | 院坝明暗两色形成突兀的斑块，树池周围尤其明显。 | 统一为旧工程同一种磨损地面扫描，分别控制低对比石色和表面起伏。见[第四轮原图](evidence/trials/rejected_court_04.jpg)。 |
| 5 | 用同一街口机位和玩家视角复查，独立重开组合源，检查五级石阶各三点的地表碰撞。 | 保留[五轮对照](evidence/iterations.jpg)、[院内玩家视角](evidence/courtyard.jpg)与[街—铺—院—街连续实走](evidence/street_court_return.mp4)。 |

修理目标和送单目标共用原游戏的距离、视线和 E 键交互。练习入口提供一辆停妥、胎压为 1.15 bar 的车；充气恢复到游戏设定的 2.4 bar，欠压会影响加速和车速。师傅可以重复检查。车远时只提示把车停到门前。正常班次的胎压随行驶距离缓慢下降，沿用班次存档，旧档采用初始胎压。

## 验证和后续批次

- [组合 Blender 源复开检查](evidence/source.json)涵盖五段檐口、承重件、院廊以及台阶与项目内南区路车道外缘的净距。檐口误差只衡量模型对描图的贴合程度。复开的修理铺网格有 32 根底部接基座、顶部接檐板的通柱。柜台上方同一轴线上有 7 段横梁，最大净跨 4.37 米。
- [连续实走物理记录](evidence/walk.json)涵盖从街入铺、充气、进院和原路返回。各段记录距离、抵达点和停滞碰撞。录像使用同一次运行的玩家镜头，按记录下来的物理帧频编码。
- [送单和旧城区回归](evidence/regression.json)另行记录接单、签收、结算、学校楼上通路及既有道路巡检。
- [原 75 个地块的台账](evidence/inventory.json)记录 4 个已经撤下的占位、1 个首次按图重建且保留原编号的地块、70 个待核地块。本院的两片临街屋面和三面屋廊共计一次地块替换。按旧墙到送单线中心线的距离，待核队列中最近的是 4 号，约 48.24 米；其与旧城相接的栏杆已有维修记录。

在 Windows 独立克隆中打开 Godot 4.6.3 的默认 `first_shift.tscn`。用 `work/scene_r24/repair_court/verify.ps1 -Run <新名> -Capture` 可用 Blender 4.3.2 重开组合源、导入 Godot 并重新走一次。楼位由 `register.py` 生成，主要建模文件是 `courtyard.py`。修改几何后先让 Blender 后台运行 `../district_500/build.py`，导出同版的 `outer_district.blend` 和 `outer_district.glb`。山城巷送单单独运行 `../shancheng_courts/verify.py`，旧城区巡检运行 `../district_patrol/verify.ps1 -Run <新名> -AllRoads -Timing`。
